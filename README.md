# Paul Weibel - Security Engineering Portfolio

Published static files for **https://paulweibel.com**.

This repository intentionally contains only the public deployment artifact and sanitized evidence used by the portfolio. Build tooling, source templates, QA scripts, working notes, and local release files are maintained separately and are not committed here.

## Public contents

- Static portfolio pages and styles
- Social/share images and icons
- Sanitized clean-room security engineering evidence
- `robots.txt`, `CNAME`, `.nojekyll`, and `.well-known/security.txt`

The browser-delivered HTML/CSS and the files in this repository are public by design. No proprietary employer source code or private working material is included.
